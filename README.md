# ◈ فینوا — FINOVA

**مدیریت هوشمند مالی شخصی — کاملاً فارسی، آفلاین و محلی — برای اندروید**

اپلیکیشن اندرویدی مدیریت پول با رابط کاربری کاملاً فارسی (RTL)، تقویم جلالی، واحد تومان و هوش مصنوعی دوگانه (آفلاین + آنلاین). تمام داده‌ها فقط روی گوشی خودتان ذخیره می‌شود.

## 📲 دانلود و نصب (نسخه ۱.۲.۰)

> **دانلود مستقیم APK:** به بخش [**Releases**](../../releases) بروید و فایل `Finova-v1.2.0.apk` را دانلود کنید — یا فایل [releases/Finova-v1.2.0.apk](releases/Finova-v1.2.0.apk) را در همین مخزن دانلود کنید.

### مراحل نصب:
1. فایل APK را روی گوشی اندرویدی خود دانلود کنید (اندروید ۱۰ به بالا — API 29+)
2. روی فایل بزنید؛ اگر پیام «نصب از منابع ناشناس» آمد، برای مرورگر/فایل‌منیجرتان اجازه نصب بدهید
3. نصب را تأیید کنید — تمام!
4. در اولین اجرا، اجازه «اعلان‌ها» را بدهید تا یادآوری اقساط کار کند

> ⚠️ پیام Play Protect ممکن است بگوید «اپ ناشناس است» — چون APK امضای شخصی دارد و در پلی‌استور نیست، «نصب در هر حال» (Install anyway) را بزنید. کل اپ متن‌باز است و می‌توانید کدش را همین‌جا ببینید.

### 🛡 نکات فنی و امنیت
- **ذخیره‌سازی:** IndexedDB (نسخه ۲ با مهاجرت خودکار از localStorage قدیمی) — «پاک‌سازی داده‌ها» واقعاً همه‌چیز را حذف می‌کند
- **سرور محلی:** وب‌اپ از `127.0.0.1` داخل خود اپ سرو می‌شود (Secure Context → IndexedDB و WebCrypto فعال، بدون نیاز به اینترنت)
- **شبکه:** درخواست‌های اینترنتی (قیمت‌ها و AI آنلاین) از پل بومی جاوا انجام می‌شود — بدون محدودیت CORS
- **WebView سخت‌گیر:** `setAllowFileAccess(false)` و دسترسی فایل/یونیورsal از فایل‌URLها بسته است
- **APK امضاشده** با کلید شخصی (SHA-256: `08511022d2bdc07215f364da55c52cb5ed8c1f664c82fe08d222135af9864e36`)

## 🏗 ساخت از سورس (بدون Android Studio!)

پیش‌نیاز: JRE 17+ ، `unzip` ، `zip` ، `curl`

```bash
# ۱) دانلود ابزارها (یک‌بار)
mkdir -p ~/android-sdk/dl && cd ~/android-sdk/dl
curl -LO https://dl.google.com/android/repository/build-tools_r34-linux.zip
curl -LO https://dl.google.com/android/repository/platform-34-ext7_r03.zip
curl -LO https://repo1.maven.org/maven2/org/eclipse/jdt/ecj/3.33.0/ecj-3.33.0.jar
cd ~/android-sdk && unzip -q dl/bt34.zip && mkdir -p build-tools && mv android-14 build-tools/34.0.0
unzip -q dl/platform34.zip && mkdir -p platforms && mv android-34 platforms/android-34

# ۲) ساخت APK
cd finova/android
bash build.sh
# خروجی: Finova-v1.2.0.apk
```

ساختار:
```
android/app/src/main/
├── AndroidManifest.xml          ← مجوزها، ویجت، اکتیویتی
├── java/com/finova/money/
│   ├── MainActivity.java        ← WebView + پل بومی + سرور محلی
│   └── FinovaWidget.java        ← ویجت دسکتاپ
├── assets/www/                  ← کل اپلیکیشن (HTML/CSS/JS خالص)
│   ├── index.html
│   ├── css/app.css              ← تم سازمانی + نئون + RTL
│   └── js/ (jalali, store, bridge, charts, ai, app)
└── res/                         ← آیکون برداری، ویجت، تم
```

## 🔄 تغییرات نسخه ۱.۲.۰

**هوش مصنوعی آنلاین حالا برای همه کار می‌کند — بدون هیچ تنظیمی:**
- 🛠 **رفع خطای «You didn't provide an API key»:** اگر نسخه قبلی در تنظیمات ذخیره‌شده آدرس OpenAI بدون کلید داشت، اپ به‌صورت خودکار آن را تشخیص می‌دهد، پاک می‌کند و به **سرویس رایگان فینوا** برمی‌گردد — دیگر هیچ‌وقت خطای انگلیسی API نمی‌بینید
- 🈯 **همه خطاهای هوش مصنوعی فارسی شدند:** خطای شبکه، شلوغی سرویس، کلید نامعتبر و… با پیام فارسی قابل‌فهم و راهنمای اقدام نمایش داده می‌شوند
- 🔁 **زنجیره جایگزین:** اگر سرویس شخصی پاسخ نداد، خودکار با سرویس رایگان تلاش می‌شود؛ در شلوغی سرویس رایگان هم یک تلاش مجدد خودکار انجام می‌شود
- ⚙️ تنظیمات AI بهبود یافت: نمایش سرویس فعال، دکمه «بازگشت به سرویس رایگان»، جلوگیری از ذخیره سرویس نیازمند کلید بدون کلید

**باگ‌های ظاهری رفع‌شده (گزارش کاربر):**
- 🐞 **همپوشانی متن روی گیج سلامت مالی** در خانه و گزارش‌ها (کانواس گیج از ظرف خود بیرون می‌زد و روی آمار می‌افتاد) — گیج حالا دقیقاً در اندازه ظرف خودش رسم می‌شود
- 🐞 **«سهم دسته‌ها (—)»** — عنوان کارت حالا نام ماه واقعی را نشان می‌دهد (مهر ۱۴۰۵)
- 🐞 **«درآمد —» در کارت موجودی** — نام ماه در برچسب درآمد برقرار شد
- 🐞 **نمودار روند ۶ ماهه خالی و گنگ** — وقتی تراکنشی نیست، پیام راهنمای دوستانه نمایش داده می‌شود
- 🐞 **تیک سبز غول‌پیکر** در «پوشش اقساط با موجودی» — حالا متن «کامل ✓» سبز مرتب
- 🐞 **«نرخ پس‌انداز ۰٪» گمراه‌کننده** — وقتی درآمدی ثبت نشده «—» نشان داده می‌شود
- 🐞 امتیاز تکراری روی گیج خانه حذف شد (عدد کنار گیج کافی است)

> APK با همان کلید نسخه قبل امضا شده — می‌توانید مستقیم روی نصب قبلی به‌روزرسانی کنید و داده‌هایتان حفظ می‌شود.
